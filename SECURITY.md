# Security policy

Please report suspected security or privacy issues privately to the repository maintainers through GitHub's private security advisory feature. Do not publish credentials, cookies, tokens, post URLs containing private information, or account exports in issues.

This tool should never ask for passwords, cookies, OAuth/API tokens, or credentials, and it must never transmit account information. Reports involving a violation of those guarantees are high priority.

The project is a browser snippet, not an X service. X UI changes can affect operation; use `DRY_RUN=true` before any real deletion.
